# Biblioteca de Grafos

Biblioteca desarrollada en Python para la implementación y estudio de estructuras de datos y algoritmos relacionados con grafos.

## Objetivo

Desarrollar una biblioteca modular que permita representar, manipular y analizar grafos, así como implementar algoritmos fundamentales de teoría de grafos y diseño de algoritmos.
